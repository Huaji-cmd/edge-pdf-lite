| #  | 问题                         | 建议                                                                                                                   |
| -- | -------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| B1 | ✅ **已解决（M10）**             | 「**区域高亮**」已落地：拖框直接盖一块，写回成**标准 `/Highlight`**（不发明新类型）。在**真正无文本层**的样本上验过：文字高亮画不出（count=0）、区域高亮能画、Edge 里文字透出            |
| B2 | ✅ **已解决（v1.3，做法与当初判断不同）** | 当初的结论是"要嵌入就得打包 8–19 MB 字体，跟 lite 冲突"，所以只画占位横线。**换个思路就成立了**：字体不进安装包，运行时从 `%WINDIR%\Fonts` 读 `simhei.ttf`，再用 fontkit **子集化**嵌入 —— 实测一份三行中文的 PDF 只多 **4.9 KB**。浏览器版读不到系统字体，仍退回占位横线（保存时明确提示） |
| B3 | ✅ **已按建议 ②（UI 说明）完成（M10）** | 欢迎页加了琥珀色警示。"用 `/T` 识别自家批注并载入 store"（建议 ①）**不做** —— 会让"擦除"语义变复杂，破坏现在这条干净的设计                                           |

## F. 多格式阅读（M15，PDF + Markdown）—— 已实现，待人工验收

策划与取舍见 `docs/M15-多格式阅读策划.md`。**PDF 那条链路没有重写**：
Markdown 是并列的新通道（`MarkdownDocument` + `MarkdownViewer`），App 只按扩展名分流。

已由自动化覆盖（`npm run test:md`，52 项 + `cargo test` 8 项）：

- [x] 打开 / 渲染：GFM 表格、任务列表、删除线、代码块、引用、自动链接、中文标题锚点
- [x] 能力矩阵：Markdown 下**不存在**批注 / 保存 / 页码 / 单双页 / 缩略图 / 撤销
- [x] 字号缩放 75%–250%，无整页横向滚动；`Ctrl+滚轮 / +- / 0`、`PageUp/PageDown/Home/End`
- [x] 大纲跳转 + 滚动高亮（相对阅读区 16px）
- [x] 页内查找（Ctrl+F）：计数、全部高亮、当前项单独高亮、Enter/Shift+Enter 逐个跳、
      无匹配文案、Esc 关闭并清掉全局高亮、`::highlight` 规则没被 scoped 拼坏
- [x] 代码高亮：带语言的块有 token span 且**文本不变**；代码块里的 `<script>` 只是文字
      （高亮不会把它变成元素）；没标语言的块保持纯文本；exe 侧 PDF / MD 徽标、文件夹无徽标
- [x] 阅读位置记忆（独立键 `epl:md-reading:`，不污染 PDF 的 `epl:reading:`）
- [x] 安全：原始 HTML 不执行、`style` 属性被清、`javascript:/file:/data:` 不落地、
      `ftp:` 与相对链接变死链、远程图片不联网
- [x] Rust 侧：`read_doc_asset` 拒绝 `..` / 盘符 / UNC / `/` 开头，SVG 不放行，
      Markdown 16 MiB / 图片 20 MiB 两道大小闸门

### 已知的取舍（不是 bug）

| 行为 | 原因 |
|---|---|
| Markdown 不能批注、不能编辑 | 产品边界；批注必须有页与坐标，Markdown 没有稳定的页概念 |
| 浏览器版本地图片要授权一次 | File System Access 是唯一合法入口；刷新后权限回落，需再点一次占位确认（浏览器规定，绕不过） |
| **拖进来的 md 看不到本地图片** | HTML5 拖放只给 File 字节、没有真实路径，读不到同目录的图。占位文案会直接说明并提示"从左侧文件列表打开"（那里有真路径） |
| 远程图片一律占位 | 不联网、不追踪；也避免低配机上被大图拖住 |
| 单篇最多自动加载 100 张本地图片 | 磁盘 IO 与 DOM 体积保护，超出的显示"未自动加载" |
| 不做公式 / Mermaid | 守住 lite；这些都会显著增加包体与长文渲染成本 |
| 代码块不标语言就不高亮 | 自动猜语言是纯 CPU 消耗，还常猜错；没标的保持等宽纯文本 |
| 页内查找搜不到"跨样式"的词 | 查找按 DOM 文本节点匹配；`**粗**体` 这类被拆成多段的词匹配不到 |
| 笔记外图片每次运行授权一次 | 授权只登记弹窗里列出的文件、不落盘；重启后要重新确认（安全姿态：路径来自笔记内容，必须用户拍板） |
