# edge-pdf-lite · 待办与验收清单

> 截至 2026-10-11。已完成的里程碑（M0 性能实验 / M2 阅读器 / 文本层 / 位置记忆 /
> 批注绘制 / 写回 PDF / 交互）见各 `docs/M*.md`，本文只列**还没做**和**需要人工验收**的。
>
> 排序原则：**数据安全 > 主力语料上的功能缺口 > 性能 > 体验**。

---

## A. 数据安全（建议优先）

| # | 问题 | 现状 | 建议 |
|---|---|---|---|
| A1 | ✅ **已解决（M10）** | 退出前拦截：`beforeunload`（刷新/关标签/后退）+ **应用内换文档 `confirm`**（这条 `beforeunload` 管不到）；工具栏常驻「● 未保存」琥珀色标记 | 按你的要求**不做自动暂存**，学 Word 只提醒。⚠️ 浏览器**不显示我们给的文案**（只显示它自己那句），所以可见标记必须提前做在页面上 |
| A2 | 覆盖原文件 | 只能**另存为** `原名(已批注).pdf`（有意为之，避免误毁原文件） | 保持现状，但在 UI 上说明一句 |

## B. 主力语料上的功能缺口

⚠️ 你的两本主力书性质完全不同，功能可用性也不同：

| 语料 | 文本层 | 高亮/下划线/删除线 | 手写/方框/文本框 |
|---|---|---|---|
| 《Computer Science》（文字版） | 有 | ✅ 可用 | ✅ 可用 |
| 《现代操作系统教程》（**整页扫描图**） | **没有** | ❌ **不可用** | ✅ 可用 |

| # | 问题 | 建议 |
|---|---|---|
| B1 | ✅ **已解决（M10）** | 「**区域高亮**」已落地：拖框直接盖一块，写回成**标准 `/Highlight`**（不发明新类型）。在**真正无文本层**的样本上验过：文字高亮画不出（count=0）、区域高亮能画、Edge 里文字透出 |
| B2 | ⚠️ **已评估，决定不做字体嵌入（M10）** | 浏览器**读不了系统字体** → 要嵌入就得打包 8–19 MB 字体，跟 lite 冲突。改成画**占位横线**（不再是一个莫名其妙的空框），文字在 `/Contents` 里没丢。真要做只有一条路：**导出时让用户选字体文件** |
| B3 | ✅ **已按建议 ②（UI 说明）完成（M10）** | 欢迎页加了琥珀色警示。"用 `/T` 识别自家批注并载入 store"（建议 ①）**不做** —— 会让"擦除"语义变复杂，破坏现在这条干净的设计 |

## C. 性能 / 架构

| # | 问题 | 现状 |
|---|---|---|
| C1 | **大文件写回未测** | 15 KB 样本上增量 8–18ms **不比**全量 2–4ms 快或小；增量的价值在峰值内存，但没在 20–50MB 的真教材上量过 |
| C2 | **writer 跑在主线程** | 大文件会卡住 UI（几秒无响应）。该搬 Web Worker |
| C3 | 600 页文档的批注层内存 | 每页最多两张 2× 位图 canvas，离屏回收已有，但**没做过内存实测** |

## D. 体验

| # | 问题 |
|---|---|
| D1 | **拖动/改大小后的批注，写回 PDF 的渲染没做跨查看器核对**（M7 遗留）。坐标一致性有不变量守着，但没端到端看图 |

| D4 | 高亮只能整条换色，不能只换一半 |

## E. 需要你人工验收的

无头浏览器测不到的东西，需要你在**真机**上过一遍：

- [ ] 双页并排时的居中与翻页手感（无头下 `#page=` 定位不可靠）
- [ ] 缩放 50% → 400% 逐档看：文字层重对齐、批注跟着重绘
- [ ] 关掉浏览器再打开同一份 PDF：**阅读位置**是否回到原处
- [ ] 画一笔 → 刷新页面 → 再打开同一份 PDF（验证 A1 到底疼不疼）
- [ ] 把保存出的 `written.pdf` 在 **Edge / 系统 PDF 阅读器**里打开，逐页核对批注外观
- [ ] 打开你那两本真教材（尤其《现代操作系统教程》）看首屏白屏时长是否可接受
