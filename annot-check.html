人工核对清单（在各查看器里逐项打勾）

在每个查看器里各打开一次样本 PDF。每一项都要看两处： ① 页面上有没有画出来（外观）② 注释面板里有没有列出来（结构）。 有些查看器不画但会列出，有些反过来 —— 两处都看才知道是哪种。

页内容页面上应该看到注释面板应该列出关注点
P1 Highlight + /AP + Z 序 黄色高亮压在 Line 2 / Line 3 上 1 条 Highlight 基准：正确做法
P2 Highlight 无 /AP + Z 序 还能画出高亮吗？ 1 条 Highlight 与 P1 对比
P3 Highlight 无 /AP + 逆时针序 与 P2 相比有没有错位 / 翻转 1 条 Highlight 与 P2 对比
P4 Ink 手写 + /AP 一条红色波浪线 1 条 Ink 扫描件唯一可用的工具
P5 FreeText 文本框 + /AP 蓝框 + 蓝字 1 条 FreeText 字体资源是否被认到
P6 Square + StrikeOut + Underline 红框 / 删除线 / 下划线 3 条 三种不同的 QuadPoints 外观
P7 Highlight + /AP + 逆时针序 应当与 P1 完全一样 1 条 Highlight 验证「有 /AP 时顺序不重要」
最要紧的三条结论（看完请告诉我）：
1. P2 如果是空白 → /AP 是必须生成的，写回方案必须强制带上它。
2. P3 如果错位或翻转（而 P2 正常）→ QuadPoints 顺序真的有影响，一律用 Z 序。
3. P7 如果和 P1 一样 → 有 /AP 时顺序无所谓，/AP 是最终兜底。
建议逐个试：Edge（你的日常）、Chrome、Adobe Acrobat（如果装了）、Firefox。 在每个里面截一张 P1~P7 的图；如果那个查看器有注释面板，再展开截一张。
